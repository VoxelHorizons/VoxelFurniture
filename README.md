# VoxelFurniture

VoxelFurniture is a placeable, interactive furniture plugin for Minecraft servers, built on [VoxelCore](https://github.com/VoxelHorizons/VoxelCore).

## Features

- Configurable furniture models, placement, hitboxes and seating
- Persistent storage, interaction animations and model variants
- Dyeable furniture, configurable highlights and optional protection integrations
- Modern ItemDisplay renderer with legacy armour-stand fallback
- Integration with VoxelCore content definitions and resource packs

## Download and requirements

**Latest stable:** [VoxelFurniture v1.0.0](https://github.com/VoxelHorizons/VoxelFurniture/releases/tag/v1.0.0) · **Requires:** [VoxelCore v1.0.0](https://github.com/VoxelHorizons/VoxelCore/releases/tag/v1.0.0) matching your Minecraft server version.

The universal Furniture JAR is named `VoxelFurniture-1.0.0-mc1.12-26.3.jar`. Folia is not supported. Review the [compatibility guide](https://github.com/VoxelHorizons/VoxelFurniture/wiki/Compatibility) for renderer and Java/Bedrock differences.
